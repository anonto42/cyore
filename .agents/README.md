# Cyore Shared Agent Workspace

`.agents/shared/` is the canonical, tool-neutral source of knowledge for AI-assisted work in this repository.

- Read `shared/agent-startup.md` first.
- Stable facts and decisions belong in `shared/memory/`.
- Non-negotiable coding and operating rules belong in `shared/rules/`.
- OpenSpec workflow skills live in `skills/openspec-*` (generated by `openspec init --tools agents`;
  regenerate with `openspec update` rather than editing by hand).
